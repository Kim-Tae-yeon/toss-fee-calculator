01 · 조회 시작

API로 매매 수수료를 모아보세요

Windows 도구에서 본인의 API 키를 입력하면 조회 가능한 주문을 모아 계산해요. 환전·기타 비용은 결과를 확인한 뒤 내역서와 대조할 수 있어요.

  1. 1. API 키 준비토스증권에서 Client ID·Secret을 발급하고 허용 IP를 설정해요.
  2. 2. 내 PC에서 조회ZIP을 풀고 실행 파일을 열어 키를 입력해요. Python 설치는 필요 없어요.
  3. 3. 결과 확인·대조원화·달러 수수료를 확인하고, 내역서가 있다면 정밀 검증으로 이어가요.
Windows 도구 다운로드 ↓API 키 발급 안내 ↗

이미 CSV·JSON 파일이 있다면 ‘파일로 계산’을 선택하세요. 모바일에서도 파일 계산을 이용할 수 있어요.

조회 범위와 API 키 사용 안내

PC 로그인과 Open API 인증은 별개예요. 키는 내 PC에서 토스 공식 인증 서버에만 사용하며 파일에 저장하지 않아요. 동일 키로 새 토큰을 발급하면 기존 토큰은 무효화될 수 있어요.

API 미지원 주문·해지 및 휴면 계좌·환전·별도 입출금 비용은 추가 확인이 필요해요. PC 인증만으로 계좌 전체 비용이 확정되지는 않아요.

01 · 자료 불러오기

내 거래 파일로 계산하세요

수수료가 기록된 CSV·TSV 또는 이 도구에서 저장한 JSON을 선택하세요.

최대 15MB · 파일은 서버로 전송되지 않아요. PDF·XLSX는 지원하지 않으며, 엑셀 파일은 CSV UTF-8로 저장해주세요.

금액 열을 확인해주세요

선택 항목 · 세금, 환급, 거래번호, 원화 환산

수수료와 세금이 합쳐진 열은 먼저 분리해주세요. 환급은 양수로 입력하며, 수수료에서 이미 뺀 환급은 다시 넣지 마세요. 원화 환산에는 거래별 환율·기준일시·출처 또는 실제 원화 부과액과 근거가 필요해요.

01 · 자료 불러오기

거래 상세를 복사해 넣으세요

  1. 토스증권 PC에서 내 계좌 → 거래내역을 열어요.
  2. 거래를 선택하고 종목명부터 수수료까지 상세 내용을 복사해요.
  3. 아래에 붙여넣어요. 여러 거래를 이어 붙일 수 있어요.

붙여넣은 거래만 계산해요. 해외주식·환전은 같은 내역을 두 번 넣지 마세요. 국내 날짜·종목별 합산 상세는 중복을 제거해요.

시작할 방법을 선택해주세요. API 키는 Windows 도구에만 입력하세요.
