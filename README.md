# 내 수수료 계산기

각자 본인의 거래내역으로 매매·환전 수수료를 계산하는 웹 도구입니다. 개인 실거래 데이터는 배포하지 않습니다.

- CSV/TSV 열 선택, JSON 가져오기, 토스증권 거래 상세 붙여넣기
- 브라우저 안에서만 계산. 서버 전송, 분석 SDK, localStorage 없음
- 소수점 8자리 고정 정수 연산, KRW/USD 분리, 누락 금액과 0 구분
- 계좌·통화·거래번호가 같을 때만 중복 제거. 값이 다르면 중단
- 국내 상세의 합산 체결은 날짜·종목·매매 방향으로 중복 제거. 해외 상세는 별도 거래로 취급
- 선택한 자료의 합계이며 전체 계좌 이력을 자동으로 보증하지 않음

## 전체 기간 조회

공식 Toss Securities Open API에 접속하는 Windows 도구를 Releases에서 제공합니다. 자신의 API 키와 허용 IP 설정이 필요합니다. 서버를 127.0.0.1에만 열고 키는 메모리에서 토스 공식 인증 서버에만 사용합니다. API 미지원 주문·해지 계좌·환전 내역은 별도입니다.

소스는 `local-client/`에서 확인할 수 있습니다. Python 3.10 이상에서 `python launch.py`로 실행합니다. Windows 배포 파일은 개인 제작이며 코드 서명되지 않았습니다.

## 파일 형식

CSV에는 통화(currency: KRW/USD), 매매 수수료(commission) 또는 환전 수수료(fxfee) 열이 필요합니다. 날짜(date), 종목(symbol), 세금(tax), 거래번호(orderId), 계좌 구분(account)은 선택입니다. 제목이 다른 경우 화면에서 직접 매핑할 수 있습니다. 공백 금액은 미확인, 숫자 0은 수수료 없음입니다. PDF 및 XLSX 직접 읽기는 지원하지 않습니다.

## 개발

`npm test`로 계산·입력 검증을 실행합니다. `python -m http.server 8767 --bind 127.0.0.1`로 확인할 수 있습니다. GitHub Pages의 main 루트를 배포합니다.

## v1.1 — 원화 환산과 대조

수수료 합계는 매매 + 환전 + 기타 수수료 − 환급입니다. 세금과 지급 이자는 별도입니다. 환급은 음수 수수료 또는 양수 refund 중 하나로만 입력합니다.

- `otherFee`: 이체·출고 등 실제 기타 수수료. 거래 원금 전체를 넣지 않습니다.
- `refund`: 아직 수수료에서 차감하지 않은 환급액 (양수).
- `interest`: 지급 이자. 수수료 합계에서 제외합니다.
- `paidKrw`: 해당 행의 순수수료에 대응해 원본에 직접 기재된 원화 부과액. 세금·이자 제외. `evidence`에 문서·페이지·행 근거를 기재합니다. 임의로 배분한 달러 취득 원가를 여기에 넣지 않습니다.
- `rate`, `rateDate`, `evidence`: 거래별 참고 환율(원/USD), 기준일시, 출처. 거래일 또는 결제일과 날짜가 맞아야 환산합니다. 현재 환율이나 직전 환전 환율을 자동 대입하지 않습니다.
- `settlementDate`: 원본의 결제일. 날짜가 없다는 이유만으로 미결제라고 단정하지 않습니다.
- `feeScope`: 도구가 CSV 내보내기 시 기록하는 누락 검증용 항목입니다. 임의 수정하지 않습니다.

참고 환산은 실제 원화 지출과 다릅니다. 여러 번 환전한 달러, 매도대금·배당금으로 받은 달러에는 수수료별 원화 취득원가가 자동으로 정해지지 않습니다. 달러 취득원가를 배분하려면 완전한 외화 현금 원장과 명시한 배분 기준이 필요합니다. 이 도구는 임의 배분하지 않습니다. 환전 수수료를 달러 원가에 포함한 뒤 다시 더하면 중복입니다.

계산은 소수점 8자리 정수 × 환율 8자리 정수를 유지하며 중간 반올림을 하지 않습니다. 최종 표시만 원 단위 반올림하고 반올림 전 값도 표시합니다. 이 정밀도는 원본 자료의 정확성이나 완전성을 보증하지 않습니다.

대조 파일은 기준 파일에 더하지 않습니다. 계좌·통화·거래번호가 일치할 때 금액 차이를 검사합니다. 계좌 명칭을 통일해야 하며, 식별자 없는 자료는 자동 병합하지 않습니다. 일별 합계 비교는 진단용입니다. 해외 현지 거래일과 KST 체결일 차이, 국내 일괄 결제와 주문별 반올림 차이를 직접 확인해야 합니다.

Windows 조회 도구는 `/api/v1/exchange-rate?dateTime=...`로 각 주문의 최종 체결시각 참고 환율을 조회합니다. 응답 통화 및 유효 시간대를 검사하며 누락 시 현재 환율로 대체하지 않습니다. 여러 시각에 부분 체결된 주문에 대한 최종 체결시각 환산은 참고치입니다. 실제 계좌를 통한 과거 환율 조회 성공은 사용자의 인증 후 별도로 확인해야 합니다.

조회 완료 후 **원화 환산·내역서 대조 열기**로 로컬 화면에서 분석하거나 JSON을 저장할 수 있습니다. API와 거래내역서 원본은 본인 PC에만 보관하세요. PDF 원본 자동 파서는 아직 제공하지 않으며, 확인된 CSV 양식으로 가져옵니다. 전체 계좌·전체 기간·환급·기타 수수료 자료가 없으면 전체 총액을 확정하지 않습니다.

### Windows 빌드

`python sync-local.py` 실행 후:

```
python -m PyInstaller --noconfirm --clean --onefile --name TossFeeAnalyzer --add-data "local-client/web;web" --add-data "local-client/audit;audit" --hidden-import ui_import --hidden-import reference_rates --paths local-client local-client/launch.py
dist/TossFeeAnalyzer.exe --smoke-test
```

검증: `npm test`, `python -m unittest discover -s tests -p "test_*.py"`.
