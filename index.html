내가 낸 수수료,
직접 확인해보세요.

본인의 거래내역을 넣으면 매매·환전 수수료를 모아드려요.
원화와 달러는 따로, 세금은 별도로 계산합니다.

1. 내 거래 파일 선택

수수료 열이 있는 CSV·TSV, 또는 이 분석 도구의 JSON 파일을 선택하세요.

파일은 서버로 전송되지 않습니다. PDF·XLSX는 지원하지 않습니다. 엑셀 파일은 CSV UTF-8로 저장해주세요.

2. 금액이 들어 있는 열 확인

수수료와 세금이 합쳐진 열은 먼저 분리해주세요. 환전 수수료 열은 해당 행의 통화 단위여야 합니다. 거래번호가 없으면 같은 금액도 별도 거래로 계산합니다.

토스 거래 상세를 복사해 넣기

  1. 토스증권 PC에서 내 계좌 → 거래내역을 엽니다.
  2. 거래 하나를 선택하고, 오른쪽 상세의 종목명부터 수수료까지 복사합니다.
  3. 아래에 붙여넣으세요. 여러 상세를 이어 붙일 수 있습니다.

붙여넣은 거래만 계산됩니다. 해외주식·환전은 같은 내역을 두 번 붙여넣지 마세요. 국내주식의 날짜·종목별 합산 상세는 중복을 제거합니다.

공식 API로 내 매매 수수료 전체 조회

거래 파일이 없다면 PC용 도구를 사용할 수 있습니다. 본인의 토스증권 Open API 키가 필요합니다. 토스 PC 로그인만으로 연결되지는 않습니다.

  1. 토스증권 공식 API 안내에서 이용 신청·키 발급·허용 IP 설정을 완료합니다.
  2. 아래 Windows 도구를 내려받아 실행합니다. Python 설치 없이 실행됩니다.
  3. 자동으로 열린 내 PC 화면에 키를 입력하고 조회합니다.
  4. 결과를 확인하거나 거래별 CSV를 저장해 이 페이지에 넣습니다.
Windows 도구 다운로드 ↓

키는 내 PC에서 토스 공식 서버에만 전송합니다. 조회 전용이며 매매 기능은 없습니다. API 미지원 주문·해지 계좌·환전 비용은 별도 확인해야 합니다. 실행 창을 닫으면 종료됩니다. 동일 API 키로 새 토큰을 발급하면 해당 키의 기존 토큰은 무효화될 수 있습니다.

직접 실행하려면 Python 소스도 제공합니다. Windows 실행 파일은 개인 제작이며 코드 서명되지 않았습니다.
